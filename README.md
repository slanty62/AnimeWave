## 🌊 About AnimeWave

**AnimeWave** — веб-приложение для просмотра и поиска аниме,
созданное на ASP.NET Core MVC.

Проект выполнен в современном тёмном стиле стриминговых сервисов
и использует PostgreSQL для хранения данных.
